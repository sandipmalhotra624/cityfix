CITYFIX BEST UI/UX DEMO
========================
Open index.html.

Pages:
Home, Report Issue, Track Issues, Issue Details, Authority/Admin Dashboard,
Database Management, Analytics, Users & Roles, Notifications.

The pages share one demo dataset through localStorage. Submit a complaint on
Report, then see it on Track/Admin/Database/Analytics. Change status from
Admin and the change persists across pages.

ROUND 1 LOGO:
The small cloud icon in the header is only a placeholder. Replace it with
the exact unchanged Round 1 logo before the final presentation.

BACKEND:
This is a polished frontend prototype for the 2-hour demo. The UI is structured
so the localStorage data layer can be replaced by MongoDB REST APIs.
